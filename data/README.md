# Dataset placement

The original notebook references an approximately 285 MB CSV downloaded from this shared file:

https://drive.google.com/file/d/1k3ZGqhQSavRmw5RkfCZc3dmQuYiyViV6/view

To run the notebook, save the CSV as `data/data_apartment.csv`. The notebook can also attempt a `gdown` download if the Drive file is accessible.

**Do not commit the CSV** unless you have confirmed you have permission to redistribute it. The repository's `.gitignore` excludes it by default.
